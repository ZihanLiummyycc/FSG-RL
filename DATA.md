# Dataset release and provenance

The FSG-RL data release includes the SFT training records, the 866-problem main GRPO training split, its 60-problem teacher-continuation subset, and a held-out 400-problem evaluation set. The latter has 97 GSM8K, 95 MathQA, 128 MATH, and 80 Omni-MATH problems. Each published evaluation row contains the question and its **public** function graph. The graph specifies subquestions, dependencies, output types, and executable interfaces. It is the same graph-conditioned input supplied to evaluated policies.

The original locked evaluation file also contains gold answers, target calls, hidden tests, and annotation audits. Those fields are **not** in the public evaluation input file. They were used for scoring only after generation. Consequently, that split supports prompt construction and qualitative analysis but **does not by itself reproduce the paper's private-test or answer-accuracy scores**. In contrast, the released **training** records retain the gold answers and verification graphs needed for training rewards; annotation audits are removed. The original scoring-file SHA256 is recorded in `reproducibility/lock_manifest.original.json`; the public evaluation export has its own SHA256 and is not byte-identical to that locked scoring file.

The evaluation split was selected from reserved source pools after excluding matching IDs and normalized problem text from the supplied training and earlier development records. This is a split-level overlap check, not a claim that upstream foundation-model pretraining could not contain these public-source questions. The 400 items remain evaluation-only and must not be used for training or checkpoint selection in a new claimed held-out comparison.
